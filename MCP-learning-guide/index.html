先读这一句

MCP（Model Context Protocol）是一套标准协议，规定「AI 应用」和「能力提供方」之间怎么互相发现、怎么调用。 它规定了消息的格式、能力的声明方式、工具的调用与返回。 任何一方只要按这套规定实现，就能和任何另一方对接 —— 不需要为对方单独写适配代码。

版本与时点

重要：请先读这一条

本合集基于 MCP 规范 2026-07-28。这次改版是一次破坏性变更：协议从「有状态的、双向的」改成了 无状态的请求/响应。旧的 initialize 握手和 Mcp-Session-Id 会话头已经被移除。

网上大量 2025 年的教程讲的是旧模型。当你看到「先 initialize 握手」「维持一个长连接会话」这类说法时， 要知道那描述的是 2025-11-25 及更早的版本，不是现在这套。

代码示例使用的 SDK：Python 用 mcp（v2 系列），Go 用 github.com/modelcontextprotocol/go-sdk（v1.7.0+）。
